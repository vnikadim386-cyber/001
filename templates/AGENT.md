# AI Relay — алгоритм агента

Проект уже инициализирован. Действуй по шагам.

## Старт сессии

1. Прочитай по порядку в **этом** репозитории:
   - `rules/core.md`
   - `rules/workflow.md`
   - `rules/coding.md`
   - `rules/build.md`
   - `rules/communication.md`
   - `PROJECT.md`
   - `STATUS.md` ← здесь точка остановки и следующий шаг

2. `README.md` — только для человека, не правила.

3. Работай по «Следующий шаг» / текущему этапу в `STATUS.md`, если человек не дал другую задачу.

## После порции работы

1. Обнови `STATUS.md` (чек-листы, этап, следующий шаг).
2. Нужные факты о стеке/версиях — в `PROJECT.md`.
3. Краткий отчёт человеку.

## Запреты

- Не меняй `AGENT.md` и `rules/` без явной просьбы.
- Не коммить секреты и keystore.
- Не выдумывай требования — спроси.
- Не делай bootstrap повторно.

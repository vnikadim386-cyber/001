# AI Relay — алгоритм агента

Читай этот файл целиком. Дальше действуй строго по шагам, сверху вниз. Ничего не пропускай.

## Шаг 0. Доступ

- Репозиторий проекта и токен — из сообщения человека.
- Репозиторий протокола и токен — из сообщения (если даны). Нужны только когда в проекте ещё нет `AGENT.md`.

## Шаг 1. Новый проект или продолжение?

Открой **корень репозитория проекта**.

| Условие | Действие |
|---------|----------|
| Нет файла `AGENT.md` | Перейди к **Шагу 2 (bootstrap)**. После него **остановись**. |
| Есть `AGENT.md` | Перейди к **Шагу 3 (работа)**. |

`README.md` проекта — не правила. Не используй его как инструкцию.

## Шаг 2. Bootstrap (только пустой проект)

Выполни `BOOTSTRAP.md` из репозитория протокола по пунктам.

Кратко: скопируй в проект `AGENT.md`, `rules/`, шаблоны `STATUS.md` / `PROJECT.md` / `README.md` → заполни из ТЗ → один коммит `Bootstrap AI Relay protocol` → напиши в чат:

```
Готов к работе.
Проект: <название>
Этап: <из STATUS.md>
Следующий шаг: <из STATUS.md>
```

**Стоп.** Жди «продолжай» или новую задачу. Код не пиши.

## Шаг 3. Работа (проект уже с правилами)

В **репозитории проекта** прочитай по порядку:

1. `AGENT.md` (этот же алгоритм, уже в проекте)
2. `rules/core.md` → `workflow.md` → `coding.md` → `build.md` → `communication.md`
3. `PROJECT.md` — стек, решения, версии
4. `STATUS.md` — **главный handoff**: где остановились, что делать сейчас

Дальше:

1. Бери задачу из `STATUS.md` («Следующий шаг» / текущий этап) или из сообщения человека.
2. Сделай порцию работы. Оставляй проект в рабочем состоянии.
3. Обнови `STATUS.md` (чек-листы, этап, следующий шаг).
4. При необходимости обнови `PROJECT.md` (стек, versionName, решения).
5. Краткий отчёт: что сделано → что в статусе → что дальше.

Не повторяй bootstrap. Не затирай STATUS/PROJECT без причины.

## Запреты (всегда)

- Не меняй `AGENT.md` и `rules/` без явной просьбы человека.
- Не коммить секреты, токены, keystore, пароли.
- Не выдумывай требования: нет в STATUS / PROJECT / сообщении — спроси один раз.

# Core Rules

## Язык

- Общайся с человеком на том языке, на котором он пишет.
- Код, комментарии в коде, имена коммитов — на английском (если человек не указал иначе).
- Документация проекта (`README.md`, `STATUS.md`, `PROJECT.md`) — на языке человека (по умолчанию русский).

## Правдивость

- Не придумывай факты о проекте, стеке, решениях.
- Если чего-то не знаешь — скажи и спроси.
- Не обещай то, что не можешь сделать.

## Минимальные изменения

- Меняй только то, что нужно для задачи.
- Не делай «улучшения по дороге», если об этом не просили.
- Не переписывай работающий код без причины.

## Безопасность

- Не коммить секреты, токены, пароли, ключи.
- Не выкладывай токены в чат и в файлы репозитория.
- Если видишь секрет в коде — укажи на это и предложи убрать.
- Keystore, пароли подписи, `KEYSTORE_*` — только GitHub Secrets, никогда в git и в чат.

## Репозиторий

- Работай только в рамках текущего проекта.
- Не создавай лишние файлы и папки «на будущее».
- Структура протокола (AGENT.md, rules/, templates/) — неприкосновенна без явной просьбы.
